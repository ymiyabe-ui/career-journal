# Career Journal

1日1分で書ける、キャリアのための日記アプリ。PWAとしてスマホのホーム画面に追加して使う。

## 使い方

- 「今日」タブを開くと、すぐに入力できる。必須は「今日の達成」だけ
- 「1行だけ書く」に切り替えると、達成の1行だけで記録できる
- 書いた日はサマリーが出る。「編集する」で直せる
- 書き忘れた日は、「記録」タブの「日付を選んで書く」で後から書ける。昨日の分は連続記録に数え、それより前の分は累計にだけ入る。「今日」タブにも、昨日が空のときは近道のボタンが出る
- 1日の区切りは午前4時。深夜に書いた分は前日の記録になる
- 「バッジ」タブに、連続記録（3・7・14・30・50・100日）と累計（10・30・50・100・365日）のバッジが並ぶ。「今日」タブの上部に「あと◯日で…」の予告が出る。バッジは保存せず記録から毎回計算するので、端末をまたいでも同じになる
- 「振り返り」タブに3つの見方がある
  - **カレンダー**：記録した日に色が付く。日付を押すとその日の記録が出て、編集もできる。記録のない過去の日は、その場で書ける
  - **推移**：週ごと（直近8週）・月ごと（直近6か月）の記入率と、達成の数（「今日の達成」に書いた行の数）の棒グラフ。今週・今月は今日までの数字で、薄く表示する
  - **サマリー**：今月・先月・直近30日・直近90日・すべての期間を選び、達成・学び・明日のアクションを日付順にまとめた Markdown を作る。コピーか .md ファイルで保存できる。評価面談や振り返り用。「すべて」を選べば全期間の Markdown の書き出しになる
- 連続7日ごとに「お休み券」を1枚もらえる（最大2枚）。1日休んだら次に記録したときに自動で使って連続をつなぐ。券が足りなければ連続は1日から。累計とバッジは消えない

## データの保存と同期

- 記録はまずブラウザの IndexedDB（端末の中）に保存する。オフラインでも書ける
- 設定タブで同期先（GAS の URL と合言葉）を入れると、Google スプレッドシートを通してスマホと PC の記録をそろえる。同じ日の記録は後から書いたほうが残る
- 同期するのは、記録したとき・アプリを開いたとき・画面に戻ったとき・電波が戻ったとき
- 同期サーバーの作り方は [gas/README.md](gas/README.md)
- 設定タブで、入力項目（名前の変更・足す・隠す・並べ替え）とバッジのしきい値を変えられる。この2つは同期されるので、スマホとPCで同じになる。「今日の達成」は先頭に固定で、必須（連続記録と達成の数の元）。項目を隠しても、過去の記録の中身は消えず、あとで戻せる
- テーマカラー（5色）とダーク／ライトは端末ごとの設定で、同期しない
- 設定タブの「JSONで書き出す」で控えを取れる。読み込むと、同じ日の記録は更新日時が新しいほうを残す
- iPhone は、ホーム画面に追加しないで使うとデータが消えることがあるので、必ずホーム画面に追加して使う

## 開発

```sh
npm install
npm run dev      # http://localhost:5173/career-journal/
npm test         # 日付の区切り・連続記録・同期のテスト（gas/ のテストも含む）
npm run build    # dist/ に出力
```

アイコンは `public/icon.svg` を直して `npx pwa-assets-generator` で作り直す。

### 構成

| 場所 | 役割 |
|---|---|
| `src/config/fields.ts` | 入力項目と1日の区切り時刻 |
| `src/types.ts` | 記録のデータの形（`id` は日付と同じ。削除は `deleted` の印） |
| `src/lib/stats.ts` | 連続記録・累計の計算（集計は保存せず毎回計算する） |
| `src/lib/streak.ts` | 連続日数とお休み券の計算 |
| `src/lib/badges.ts` | バッジの獲得判定（獲得日つき） |
| `src/lib/calendar.ts` | 月のカレンダーの並び（日曜はじまり） |
| `src/lib/trends.ts` | 週・月ごとの記入率と達成の数 |
| `src/lib/summary.ts` | 期間の指定と、成長サマリーの Markdown 作成 |
| `src/config/milestones.ts` | バッジのしきい値と名前、お休み券のルール |
| `src/lib/merge.ts` | 同じ日の記録の競合解決（更新日時が新しいほうを残す） |
| `src/storage/` | 保存先の抽象（`repository.ts`）と IndexedDB 実装（`dexie.ts`）、テスト用のメモリ実装 |
| `src/sync/sync.ts` | 未送信分を送り、変わった分を受け取る同期処理 |
| `src/store.ts` | 画面から使う状態（Zustand） |
| `gas/` | 同期サーバー（Apps Script）。スプレッドシートへの保存とリマインドメール |

## 公開

`main` に push すると GitHub Actions がテスト・ビルドして GitHub Pages に公開する。
初回だけ、リポジトリの Settings → Pages → Source を「GitHub Actions」にする。
